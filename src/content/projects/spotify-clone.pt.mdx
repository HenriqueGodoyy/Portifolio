## Sobre

Meu primeiro projeto: um clone simplificado da interface do Spotify, feito para aprender e praticar **HTML** e **CSS**.

O objetivo é reproduzir a interface visual da plataforma de streaming.

## Status

- Estrutura base em HTML finalizada
- Estilização com CSS em andamento
- Funcionalidades dinâmicas com JavaScript ainda por vir

É um projeto de estudo, sem relação com o Spotify.
