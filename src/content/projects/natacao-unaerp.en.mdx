## About

A system built for the **Unaerp Esportes** university extension project, starting with the UNAERP swimming team.

The goal is to make it easier to follow each athlete's progress over time, so coaches can review performance in an organized way.

## What it does

- Athlete registration
- Performance metrics logging
- Individual progress history
- Progress charts
- Admin panel for coaches

## Next steps

- Finish the web dashboard
- Add user authentication
- Turn the system into a mobile app
- Automatic notifications and reports

The project is in development and uses a private Supabase database, so it does not fully run without credentials.
